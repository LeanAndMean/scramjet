Text typed during a turn is hidden and kept for the next prompt; as in Scramjet, Escape cancels a turn, `/compact` or a `!` command and keeps that text, Ctrl-C cancels and discards it (a reader thread takes the keys in non-canonical mode, `src/agent_cli/type_ahead.rs`). As in Scramjet, a bash call line shows the whole command, every line of it (`e1f459d`). Tool results show a short preview: the bash output tail, a numbered diff for edits. While a command runs for more than a second, its last five output lines update above the `running` line. A dim status line says what the agent waits for, with elapsed seconds (`thinking`, `preparing <tool>` while a call streams, `running` after a second of tool time). Reasoning summary parts are separate paragraphs; Ctrl+T, at the prompt or during a turn, hides the reasoning that streams next behind a dim `Thinking...` line or shows it again, with `Thinking blocks: hidden`/`visible` on the status line or under the prompt, as in Scramjet (during a turn Ctrl+T is the terminal's quit character with `NOFLSH`, so text typed ahead stays queued; Ctrl-C still discards it; `f673b7f`). As Scramjet's Shift+Tab, Shift+Tab at the prompt sets the reasoning effort to the next level the model's Proxy card lists (`reasoning.levels`, after the card's default when none is set), with `Thinking level: X` under the prompt; it is saved as a `thinking_level_change` line, restored on resume unless `--effort` is given, kept by `/new`, sent fitted to the current card as Scramjet clamps it, and named on the startup, `/model`, `/resume` and `/fork` lines (2026-11-02). As in Scramjet's editor, a `/` that starts the prompt lists the commands under it, narrowed as the name is typed, and Tab completes the path before the cursor, listing several matches (`3763c82`). Streamed reasoning and replies wrap between words, with list items continuing under their text and their markdown styled (bold, code spans, headings, fenced code blocks). The retry wait counts down on the status line. `!command` runs a shell command from the prompt without a model turn, shows its last 20 lines and adds Scramjet's ``Ran `command` `` message to the context for the next prompt; `!!command` leaves it out (2026-10-31). As in Scramjet, `/resume`, `/fork`, `/tree` and `/model` open a list under the prompt to choose from with the arrow keys, Enter and Escape (`src/agent_cli/select.rs`, 2026-11-02), and typing in the `/resume` and `/model` lists filters them as Scramjet's selectors search (`src/agent_cli/fuzzy.rs`, 2026-11-02); piped input still gets numbered lists, and `/resume N`, `/fork N`, `/tree N`, `/model ID` choose directly.
