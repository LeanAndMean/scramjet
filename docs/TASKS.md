# Tasks

Short list of current and next work. Git history records what was done.

## Current state (2026-10-30)

- `scramjet-rs agent` is a usable interactive coding agent through Proxy (`gpt-6-luna` by default): read/write/edit/bash tools, project AGENTS.md/CLAUDE.md context, approvals, resumable sessions, retries of transient provider failures, streamed reasoning summaries and replies, and an inline prompt editor (bracketed paste without sending, multi-line input, editing keys, history from the session, type-ahead flushed before approvals). Text typed during a turn is hidden and kept for the next prompt. Tool results show a short preview: the bash output tail, a numbered diff for edits. While a command runs for more than a second, its last five output lines update above the `running` line. A dim status line says what the agent waits for, with elapsed seconds (`thinking`, `preparing <tool>` while a call streams, `running` after a second of tool time). Reasoning summary parts are separate paragraphs, and streamed reasoning and replies wrap between words, with list items continuing under their text and their markdown styled (bold, code spans, headings, fenced code blocks). The retry wait counts down on the status line. `/new` starts an empty session without exiting; `/compact [focus]` replaces all but the last ~20k tokens with a summary, as Scramjet's compaction does; `/model` lists the endpoint's Responses models and `/model ID` switches to one (other models' encrypted reasoning is not replayed; `--continue` keeps the last model used). Approval questions show control and text-direction characters as escapes and repeat a bash command only when it has more than one line (the call line shows the first); answering `a` allows all later tool calls until exit. Ctrl-C at an approval question cancels the turn (recorded for the model as cancelled before the call ran). Requests carry the session id as `prompt_cache_key`. Tool paths starting with `~` are in the home directory. The usage line after each turn ends with how full the context was at the last response (`context 53k/1.1M (5.0%)`, the window from Proxy's `/api/model-cards`). Verified live on scratch projects, including a `--version` change to a clone of this repo.
- The original first-provider goal is met: two fresh `coding` invocations through Proxy wrote a haiku, then wrote and ran a Python reader whose output matched the file.
- Earlier offline demos (runtime, readers, retained TUI probes, haiku, provider validation pair) remain in the tree as development fixtures.

## Open questions

For the user, reviewed with `/rs:steer`. None blocks current work.

- **Approval policy:** every bash command asks (29 questions in one night run, mostly read-only `rg`, `git status`, `cargo test`). Scramjet does not ask before bash at all. Keep asking, ask only for some commands, or follow Scramjet?
- **Reasoning display:** summaries print in full (three filled a 40-row window once). Scramjet shows them by default and hides them with `hideThinkingBlock` and Ctrl+T. Add a way to hide them?
- **Claude models:** need an Anthropic Messages client (`/v1/messages`); Proxy rejects them on `/v1/responses`. Add that route?
- **Proxy's DeepSeek route:** its gateway reuses `output_index` 0 and sometimes drops a reply's first text delta; the client now tolerates both. Worth fixing in Proxy?
- Choices made in the `/compact` work, open to revisit: the summary prints in full (Scramjet shows a preview of up to 4096 characters and expands it on request); a split turn's two summaries are requested one after the other (Scramjet sends them in parallel); the status line says `thinking` while compacting (Scramjet: `Compacting context...`).
- Choices made in the `/model` work, open to revisit: an unknown `/model ID` prints an error instead of Scramjet's filtered selector; the model is remembered for `--continue` only once it produced a reply (a switch without a reply is not saved); response items in session files carry a `_scramjet_model` field, never sent to the endpoint; a lossy stream's block is rewritten in place rather than repeated.
