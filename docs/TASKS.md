Text typed during a turn is hidden and kept for the next prompt; as in Scramjet, Escape cancels a turn, `/compact` or a `!` command and keeps that text, Ctrl-C cancels and discards it (a reader thread takes the keys in non-canonical mode, `src/agent_cli/type_ahead.rs`). While a command runs for more than a second, its last five output lines update above the `running` line. A dim status line says what the agent waits for, with elapsed seconds (`thinking`, `preparing <tool>` while a call streams, `running` after a second of tool time). Reasoning summary parts are separate paragraphs; Ctrl+T, at the prompt or during a turn, hides the reasoning that streams next behind a dim `Thinking...` line or shows it again, with `Thinking blocks: hidden`/`visible` on the status line or under the prompt, as in Scramjet (during a turn Ctrl+T is the terminal's quit character with `NOFLSH`, so text typed ahead stays queued; Ctrl-C still discards it; `f673b7f`). Streamed reasoning and replies wrap between words, with list items continuing under their text and their markdown styled (bold, code spans, headings, fenced code blocks). The retry wait counts down on the status line. `!command` runs a shell command from the prompt without a model turn, shows its last 20 lines and adds Scramjet's ``Ran `command` `` message to the context for the next prompt; `!!command` leaves it out (2026-10-31).
