# In an editor (ACP), early

[Back to the README](../../README.md)

`scramjet acp [options]` runs Scramjet as an [Agent Client Protocol](https://agentclientprotocol.com) (v1) agent, for editors and other clients that start an agent and speak JSON-RPC on its stdin and stdout; the options are the full screen's. So far it opens new sessions (`session/new`) and runs prompts in them, with their images (`session/prompt`, `session/cancel`), with the replies, reasoning, tool calls (their arguments, files and edits' diffs) and their output, and the context's usage streamed as updates; a prompt sent while a turn runs steers it (its images as the paths of files they are saved to, as a pasted image), the client's MCP servers are started with the session's, and command sets' commands and skills are listed for the client. With `--ask`, the calls it would ask about, and publications, wait for the client's permission (`session/request_permission`); the agent's questions are the client's forms where it offers them (`elicitation/create`), and a finished command's next steps are offered to it. The model, thinking level and autopilot are config options (`session/set_config_option`; one set during a turn applies at its next pause, as `/model` typed then does). Saved sessions are listed (`session/list`), resumed (`session/resume`), loaded with their history replayed (`session/load`), closed and deleted; sign-in goes through `authenticate` and `logout`. Scramjet's own extensions add next steps, compaction, renaming, forks, branches and `/tree`, export, usage, `!` commands, API keys and a client's catch-up. It passes ACP's test kit, and has been tried in Toad, Zed and PyCharm (list it in `~/.jetbrains/acp.json` under `agent_servers`, `{"command": "scramjet", "args": ["acp"]}`). [RPC.md](https://github.com/LeanAndMean/scramjet/blob/main/docs/RPC.md) has the protocol's details.
